# 视频格式转换技能

## 目的

本技能为代理提供完整的视频文件格式转换解决方案，基于系统安装的 FFmpeg 工具。支持实现以下功能：

- 视频格式之间的相互转换（如 MP4 → MKV、AVI → MOV 等）
- 视频编码格式转换（如 H.264 → H.265、MPEG-2 → VP9 等）
- 视频分辨率调整（如 720p → 1080p、4K → 1080p 等）
- 帧率设置（如 30fps → 60fps、24fps → 30fps 等）
- 比特率控制和质量优化
- 音频轨道处理和同步
- 视频时长剪辑和关键帧提取
- 元信息提取和嵌入
- 批量视频文件转换处理

## 使用时机

- 用户需要将视频文件从一种格式转换为另一种格式时
- 用户需要调整视频编码、分辨率或帧率时
- 用户需要批量处理视频文件时
- 用户需要提取或修改视频的元信息时
- 用户需要视频质量优化或压缩时

## 不适用时机

- 用户需要视频特效制作或剪辑时
- 用户需要视频编辑软件高级功能（如画面分割、多画面合一等）时
- 用户需要纯音频处理时
- 用户需要系统范围内 FFmpeg 工具安装时（本技能假设 FFmpeg 已安装）

## 工作模式与权限

- **检查 (default, read-only)**：验证 FFmpeg 是否可用，检查源视频文件信息，列出支持的编码格式、容器格式等。无文件写入或系统修改。
- **计划**：选择目标格式，配置转换参数（编码、分辨率、比特率、帧率等），制定批量处理计划。无文件执行，仅验证参数和计划。
- **应用**：执行视频格式转换，使用 FFmpeg 工具进行实际的文件转换。可能写入输出文件，可能进行网络访问（下载模板等）。需要用户授权。
- **验证**：确认转换后的视频文件有效性，检查文件大小、时长、编码等属性。确保无意外 side effect。

## 标准工作流程

1. **建立上下文**
   - 确定工作区路径
   - 识别源视频文件（单个或多个）
   - 确认目标格式和质量要求

2. **检查**
   - 验证 FFmpeg 是否可用 (`ffmpeg -version`)
   - 检查源视频文件信息 (`ffprobe`)
   - **先探测 `ffprobe` 是否可用**（`command -v ffprobe`）：宿主注入哪些工具随版本变化，实测既出现过 `ffprobe: command not found`，也出现过 `ffmpeg`/`ffprobe` 同时可用。缺失时按 `references/guide.md`"ffprobe 可用性"一节的顺序兜底（从 `ffmpeg` 实现路径反推同目录，或退回 `ffmpeg -i` 读基本信息）
   - 列出可用编码格式和容器格式（`ffmpeg -encoders | grep video` / `ffmpeg -formats`）
   - 验证源文件路径和权限
   - **探测目标编码器是否真实可用**：目标编码器须在 `ffmpeg -encoders` 列表中且实测能跑（详见 `references/guide.md`"实测支持的格式与编码"）。`opus`/`vorbis` 等实验编码器（标记位带 `X`）需 `-strict -2`，否则会产出 0 字节文件；本构建无 `libvorbis`，要 Opus 直接用 `libopus`

3. **计划**
   - 选择目标格式和编码
   - 配置转换参数（分辨率、帧率、比特率、采样率等）
   - 决定输出路径和命名规则
   - 制定批量处理顺序
   - 请求用户确认计划

4. **应用**
   - 执行 FFmpeg 转换命令
   - 处理单个或多个视频文件
   - 处理可能的错误和警告
   - 记录转换结果和日志

5. **验证**
   - 确认输出文件存在且有效
   - 检查转换后的视频信息（`ffprobe` 复核编码、分辨率、帧率）
   - 验证文件大小和时长
   - **不要只看退出码 0**，实测有三类"退出码 0 但不成功"或"有文件但内容是坏的"：
     - 实验编码器（`opus`/`vorbis`）无 `-strict -2` → 退出码 88 + 0 字节文件
     - 输出文件已存在且未写 `-y` → 打印 `Not overwriting - exiting`，**退出码仍是 0**，输出没更新
     - 编码/容器不匹配（如 H.265 塞 WebM）→ 退出码 234，但可能留下几百字节残file
   - 判定成功的顺序：**退出码 → 文件大小 → `ffprobe` 能解析出预期编码与时长**，三者都过才算成功
   - 报告任何异常或警告

## 安全与约束

- **检查模式默认只读**：仅查询 FFmpeg 可用性和视频文件信息，不修改任何文件
- **应用模式需要授权**：转换操作可能写入文件，需要用户明确授权
- **网络访问**：仅在需要时访问网络，下载转换模板等，可能需要用户授权
- **文件路径**：所有文件操作均限制在工作区内，不允许访问系统根目录
- **参数验证**：在应用前验证所有参数，避免非法参数导致系统错误
- **错误处理**：遇到错误时给出明确提示，建议解决方案

## 事实、推断和结果标记

- `Verified`：视频转换成功，输出文件有效；证据包括 FFmpeg 成功返回和可读取的视频信息
- `Likely`：计划合理，参数配置正确，但尚未执行转换
- `Needs Verification`：用户已批准计划，但尚未执行转换
- `Unknown`：必要信息缺失（如 FFmpeg 不可用、源文件不存在等），需要进一步查询

```

参数配置：分辨率、帧率、比特率等
输出路径：输出文件路径

```

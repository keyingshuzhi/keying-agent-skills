# Dependency Auditor｜依赖审计技能

> **依赖风险必须对应版本、来源和可核验的公告；不以猜测替代漏洞证据。**

- 标识：`dependency-auditor`
- 版本：`0.1.0`
- 分类：`development`
- 作者：Keying Dev
- 类型：Agent Skill（指令与工作流定义，不自动授予工具权限）

## 1. 目标与交付

面向软件依赖和供应链风险的审计技能，核对 manifest、lockfile、实际安装版本和构建环境，识别兼容性、漏洞证据、许可证和来源可信度风险。

以**可核验信息**支持工程决策。证据不足时明确保留未知；工具未执行时不能描述为已执行。

## 2. 适用场景

- 审计 Python / npm 项目依赖是否存在风险。
- 检查 lockfile 与实际安装版本是否一致。
- 评估升级某个依赖的兼容性影响。
- 梳理项目许可证与依赖供应链风险。

## 3. 不适用及与其他 Skill 的边界

- 不涉及依赖的代码安全审查 → code-reviewer。
- 正在诊断具体报错且原因不明 → bug-investigator。
- 直接要求安装/升级全部依赖 → 需要明确变更授权与实施计划。
- 只询问某个项目的技术栈 → project-analyst。

## 4. 工作模式与权限

- **分析模式（默认）**：读取、检索、规划、给出建议；不自动修改源文件、配置、锁文件或远端系统。
- **执行模式**：仅在用户请求且工具权限、环境隔离、安全评估通过后执行必要操作；仍遵循最小副作用原则。
- **强只读模式**：用户说“只分析/不要修改”时，任何写入、安装、格式化、部署或提交都禁止。
- **未知环境**：没有权限、没有工具或证据不足时说明限制并输出可执行的下一步，不臆造结果。

## 5. 标准工作流

### 5.1 确认审计边界

确定生态系统、工作区、环境、直接与间接依赖范围，以及用户关注的安全/兼容/许可风险。

### 5.2 盘点可重复证据

读取 manifests、lockfiles、SBOM、依赖树、运行时与系统架构；识别单一项目、多工作区和条件依赖。

### 5.3 核对解析结果

对比声明约束、锁定版本和实际安装；未能访问安装环境时仅报告锁文件所示版本，不冒充运行时事实。

### 5.4 查证外部风险

若可访问可信公告/数据库，记录漏洞 ID、影响版本范围、修复版本、查询时间、来源及适用条件；离线时仅报告未核验风险，不能断言最新 CVE 状态。

### 5.5 评估影响

结合实际使用、可达性、运行时平台、传递路径及许可证条件分类；CVSS 不等于项目实际风险。

### 5.6 制定处置建议

按必要性、兼容性与迁移成本建议最小版本升级、隔离、替换或保持现状；不自动执行升级。

### 5.7 生成审计报告

包含范围、时间点、证据、严重度、可信度、建议和遗漏范围；不得声称完成全面供应链审计。

## 6. 安全和证据约束

- 默认只读，不运行可能隐含安装、升级或修改锁文件的命令。
- 不得自动下载或执行来源不明的安装脚本。
- 避免输出 .npmrc、pip 配置及私有源中的凭据；仅报告脱敏信息。
- 没有实时漏洞数据库或官方公告时必须写明“未验证最新漏洞状态”。
- 许可证相容性需视发布方式、依赖类型和具体条款判断，不替代专业法律意见。
- 依赖可疑不意味着恶意；避免无证据的恶意软件断言。

## 7. 事实、推断与结果标注

- `Verified`：有直接代码、配置、工具输出或可复现验证支持；写明来源、范围与时间。
- `Likely`：多条证据支持但尚缺关键验证；须标注缺口。
- `Needs Verification`：合理怀疑，缺乏核验；不得作为既成事实。
- `Unknown`：证据不足或不可访问；说明所需信息。

不得以模型推理取代真实测试、测量、漏洞公告或运行结果。引用文件时尽量标注路径与行号；引用命令时记录退出码与环境。

## 8. 默认输出格式

```text
审计范围/生态/时间：
证据来源（manifest/lockfile/installed/SBOM/公告）：
依赖清单与解析状态：
发现项（包、版本/范围、路径、风险、证据、置信度）：
安全公告核验状态与查询时间：
兼容性/许可证影响：
优先处置建议及回滚：
未覆盖范围和剩余风险：
```

如果不存在明确发现，报告“本次范围内未发现足够证据支持的重大问题”，**不得**暗示全局零风险。

## 9. 结束与移交

- 已形成与证据匹配的结论，且风险和未验证事项清楚；或
- 剩余验证需额外权限、环境、用户输入，继续操作风险高；或
- 当前范围已经覆盖，继续扩展无法明显提高结论质量。

与其他 Skill 协作时只传递任务相关的证据、范围及未解决问题，不自动启动无关全仓库扫描。
